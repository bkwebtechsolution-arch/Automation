LOGIN SETUP

Set these environment variables before starting/deploying the Flask app:

ADMIN_USERNAME=your_username
ADMIN_PASSWORD=use_a_strong_unique_password
FLASK_SECRET_KEY=use_a_long_random_secret_value

Open the app at /login. Successful login opens the existing document form.
The Logout button clears the login session and returns to /login.

No default username or password is created. This avoids shipping a public
default credential in the application source.
